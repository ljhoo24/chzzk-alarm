초기 설정 체크리스트

  • Windows 설정 → 시스템 → 알림에서 Google Chrome 알림이 켜져 있는지 확인
  • Windows 방해 금지 모드(집중 지원)가 켜져 있으면 알림 배너가 뜨지 않음(알림 센터에는 남음)
  • 크롬 설정 → 시스템 → Google Chrome을 닫았을 때 백그라운드 앱 계속 실행 켜기 권장
